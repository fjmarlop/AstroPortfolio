(Network Mapper) es una herramienta de código abierto diseñada para la exploración de redes y auditoría de seguridad. Su popularidad se debe a su potencia, versatilidad y capacidad para proporcionar una visión detallada del estado de una red, lo que la convierte en un recurso esencial tanto para administradores de sistemas como para profesionales de la ciberseguridad.

Originalmente desarrollada por Gordon Lyon (Fyodor), Nmap permite descubrir dispositivos conectados a una red, identificar puertos abiertos, determinar servicios activos y sus versiones, e incluso detectar sistemas operativos. Todo esto lo hace utilizando técnicas avanzadas de escaneo que pueden ajustarse según el nivel de profundidad y sigilo requerido.

Gracias a su constante desarrollo y comunidad activa, Nmap es hoy en día una herramienta imprescindible en cualquier fase de un análisis de seguridad: desde el reconocimiento hasta la evaluación de vulnerabilidades. Además, su interfaz gráfica (Zenmap) facilita su uso a usuarios menos familiarizados con la línea de comandos.

Comandos más comunes de Nmap

1 - Escaneo rápido (ping scan) 

    nmap -sn 192.168.1.0/24

Este comando realiza un escaneo de ping en la subred 192.168.1.0/24, identificando los dispositivos activos en esa red.

2 - Detección de versión de servicios

    nmap -sV 192.168.1.1

Este comando escanea el host 192.168.1.1, identificando los servicios activos y sus versiones.

3 - Detección de vulnerabilidades

    nmap --script=vuln 192.168.1.1

Este comando utiliza scripts de Nmap para buscar vulnerabilidades conocidas en el host 192.168.1.1.

4 - Escaneo combinado

    nmap -sS -sV -O -A 192.168.1.1

Este comando realiza un escaneo completo del host 192.168.1.1, incluyendo detección de servicios, versiones y sistema operativo.

5 - Escaneo HTTP con scripts NSE

    nmap -p 80,443 --script=http-title,http-headers 192.168.1.1

Este comando escanea los puertos 80 y 443 del host 192.168.1.1, utilizando scripts para obtener el título de la página y los encabezados HTTP. Puedes añadir más scripts NSE para análisis web.
